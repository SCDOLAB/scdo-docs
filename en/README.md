# SCDO Laboratory

SCDO Laboratory is a blockchain technology company. We build and run practical tools on the SCDO network:

* **SCDO Wallet**: a desktop wallet for Windows and macOS, and a mobile wallet for Android.
* **GPU Share**: a small Windows program that puts an idle NVIDIA graphics card to work on verifiable compute. Every payout is an ordinary transaction on SCDO Shard0 (EVM) that anyone can look up.
* **On-chain tools**: the SCDO Scan explorer, the SCDO Web Wallet and public network endpoints for developers.

## The SCDO network

SCDO Shard0 (EVM) is an EVM-compatible proof-of-work network:

| Item | Value |
| --- | --- |
| Network name | SCDO Shard0 (EVM) |
| Chain ID | 5680 (0x1630) |
| RPC URL | https://scdoscan.io/rpc/0 |
| Currency symbol | SCDO |
| Block explorer | https://scdoscan.io |

SCDO Shard1 (Classic) through SCDO Shard4 (Classic) are the Classic shards. They use Classic addresses such as `1S01...` and work with the SCDO Web Wallet and the desktop SCDO Wallet, not with MetaMask.
