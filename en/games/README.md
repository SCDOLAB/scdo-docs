# Games overview

9Y9 PTY LTD, trading as SCDO Laboratory, publishes free casual games on https://scdoscan.io/games/. They run in the browser with no download and no account.

| Game | What it is | Uses SCDO? |
| --- | --- | --- |
| [Shard Miner](shard-miner.md) | Tap-to-dig idle game with the SCDO kitten miner | No. Sparks are fictional points kept in your browser. |
| [Shard Miner · Real Compute](shard-miner.md#shard-miner-real-compute) | Dig game with an optional, opt-in CPU mining mode for Classic Shard1 | Optional: mining rewards go to your own `1S01…` address via the pool |
| [Thank-you wheel and bug bounty](wheel.md) | Free wheel for SCDO Shard0 EVM addresses, plus a fixed bug bounty | Yes, wheel balances in SCDO; withdrawals need KYC |
| [SCDO Kittens](kittens.md) | On-chain virtual collectibles on Shard0 | Yes, gas, breeding and market fees |
| Kitten Devil Levels, Kitten Crazy Car | Other SCDO originals | No |
| Third-party casual games | Provided by GamePix | No |

## Ad disclosure

Third-party games on the games page are provided by GamePix. Their ads play inside the games and 9Y9 PTY LTD, trading as SCDO Laboratory, receives a share of that ad revenue. These games are free, need no account and involve no real money, betting or prize draws. Playing them does not earn or cost any SCDO.
