# Getting started

Three steps get you onto SCDO.

## 1. Get a wallet

* **SCDO Wallet** for Windows, macOS (Apple silicon) or Android: see [SCDO Wallet](wallet.md). Download only from https://scdoscan.io/downloads/wallet/.
* **MetaMask** or another EVM wallet for SCDO Shard0 EVM (`0x` addresses): see [Add SCDO Shard0 EVM to MetaMask](metamask.md).
* **SCDO Web Wallet** at https://scdoscan.io/wallet/ for Classic accounts (`1S01...`).

## 2. Pick the right network

Most users and all EVM tools use **SCDO Shard0 EVM** (chain ID 5680). Classic shards use different addresses and do not work in MetaMask. See [Networks and shards](networks.md).

## 3. Check everything on the explorer

Search any `0x` address, `1S0x...` address or transaction hash on https://scdoscan.io. Confirmed transactions are final.

## Get SCDO

* Mine it with a GPU: see [Mining overview](../mining/README.md).
* Run a public full node and receive node rewards: see [Node rewards](../mining/node-rewards.md).

## Safety rules

* Download software only from https://scdoscan.io.
* Never share a private key, recovery phrase, account file or `worker.key`. 9Y9 PTY LTD, trading as SCDO Laboratory, will never ask for them.
* Type https://scdoscan.io yourself; watch for look-alike domains and fake RPC endpoints.
