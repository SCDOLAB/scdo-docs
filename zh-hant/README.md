# SCDO 實驗室

SCDO 實驗室是一家區塊鏈科技公司，在 SCDO 網路上開發並營運實用工具：

* **SCDO 錢包**：Windows 與 macOS 桌面錢包，以及 Android 行動錢包。
* **GPU 算力共享**：一個小型 Windows 程式，讓閒置的 NVIDIA 顯示卡參與可驗證的運算。每一筆發放都是 SCDO Shard0 (EVM) 上的一般交易，任何人都能查詢。
* **鏈上工具**：SCDO Scan 區塊瀏覽器、SCDO 網頁錢包，以及提供給開發者的公開網路端點。

## SCDO 網路

SCDO Shard0 (EVM) 是相容 EVM 的工作量證明網路：

| 項目 | 數值 |
| --- | --- |
| 網路名稱 | SCDO Shard0 (EVM) |
| 鏈 ID | 5680（0x1630） |
| RPC 網址 | https://scdoscan.io/rpc/0 |
| 貨幣符號 | SCDO |
| 區塊瀏覽器 | https://scdoscan.io |

SCDO Shard1 (Classic) 到 SCDO Shard4 (Classic) 是 Classic 分片，使用 `1S01...` 這類 Classic 位址，可用 SCDO 網頁錢包與桌面版 SCDO 錢包管理，無法在 MetaMask 中使用。
