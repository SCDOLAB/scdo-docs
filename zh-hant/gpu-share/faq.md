# GPU 算力共享常見問題

## 需要註冊或實名認證嗎？

不需要。不需實名認證、電子郵件或註冊表單，下載、解壓縮、雙擊即可。請看[安裝程式](install.md)。

## 需要先準備錢包嗎？

不需要。程式第一次啟動會自動建立 `%APPDATA%\SCDO\gpu-share\worker.key`，它對應的 0x 位址就是你的收款位址。請立刻備份這個檔案，勿交給任何人。

## 我的位址在哪裡看？

在 https://scdoscan.io/gpu-share/?ref=gitbook#check 的查詢欄輸入位址，或到 https://scdoscan.io 搜尋該位址，就能看到鏈上紀錄。

## 重新安裝或換資料夾，位址會變嗎？

不會。金鑰存在 `%APPDATA%\SCDO\gpu-share`，只要沒有刪除這個資料夾，重裝後仍是同一臺工作機、同一個位址。

## 需要什麼硬體？

Windows 10／11 64 位元，NVIDIA 顯示卡（4GB 顯示記憶體以上）。

## 支援哪些系統？

Windows 與 Linux 都支援閒置挖礦與 Folding@home。下載頁目前提供 Windows 版。

## 電腦空閒時會做什麼？

先挖 SCDO：官方礦工包內的 Rigel 用你的位址直連 SCDO 公開礦池，不需要本機節點。Rigel 為閉源軟體，收取 0.7% 開發者費用。挖礦無法啟動時，改由官方 Folding@home 用戶端接手，以 SCDO Laboratory 團隊（#1068523）參與醫學研究運算。

## 會佔用多少資源？

程式以 10 分鐘平臺時段與 10 分鐘留給你的時段輪替。運算時顯示卡負載會升高，機殼散熱不好時請改善通風，或只在外出、睡覺時開著。要玩遊戲時，先關掉程式。

## 怎麼停止？

關閉程式視窗，或在工作管理員結束 `scdo-gpu-share-worker-1.2.4-win-x64.exe`。程式不會安裝 Windows 服務。

## 怎麼解除安裝？

刪除解壓縮後的資料夾。要完全移除，請一併刪除 `%APPDATA%\SCDO\gpu-share`（若有 `%AppData%\scdo-gpu-worker` 也一起刪）。若之後可能再用，請先備份 `worker.key`。

## 同一個網路有好幾臺電腦可以嗎？

可以，每臺電腦各自建立位址。每個公用 IP 位址最多可註冊 20 臺活躍工作機，離線超過 7 天的不計入。若暫時無法註冊，程式會繼續挖礦與執行 Folding@home，並自動重試。

## Windows 跳出「Windows 已保護您的電腦」是中毒嗎？

不是。這個程式沒有程式碼簽章，所以可能出現這個提示。請先用下載頁上的雜湊值核對壓縮檔，再按「其他資訊」→「仍要執行」。

## 安全嗎？我的資料會被傳出去嗎？

私鑰留在你的電腦，程式只送出簽名。執行前請核對雜湊值。發放都是 SCDO Shard0 (EVM) 上的一般交易，可在 https://scdoscan.io 查詢。程式由澳洲公司 9Y9 PTY LTD（SCDO 實驗室）營運。

## SCDO 從哪裡來？

三個來源，都不是收入承諾：

1. **付費任務：** 已驗證的任務由 SCDO 實驗室金庫在 SCDO Shard0 (EVM) 上結算。
2. **閒置挖礦：** 由礦池直接付給你的位址。
3. **Folding@home：** 在 SCDO 發放比例設定前不發放，目前比例為 0。
