# 招募：顯卡運算貢獻者

SCDO 實驗室是一家區塊鏈科技公司，現正招募願意把顯卡算力分享給 SCDO 網路的夥伴。

**職位：** 顯卡運算貢獻者

**地點：** 遠端。免面試、免註冊，開始時不需要錢包。

**條件**

* 一台 Windows 電腦
* 一張 NVIDIA 顯卡，顯示記憶體 4GB 以上

**應徵方式**

1. 到[下載頁](https://apeccapital.org/gpu-share/?ref=gitbook-recruit-zh)下載 SCDO 顯卡共享工作程式（約 9MB）。
2. 解壓縮後雙擊執行。
3. 程式會自動產生位址並連上 SCDO 公開礦池。想停止時，關掉視窗即可。

{% hint style="warning" %}
首次執行會產生錢包密鑰 `%APPDATA%\SCDO\gpu-share\worker.key`，請務必備份，你的位址由它決定。
{% endhint %}

程式也支援 Folding@home 醫學研究，隊伍為 **SCDO Laboratory**（隊伍編號 1068523）。

安裝步驟請看[安裝工作程式](install.md)，常見問題請看[常見問題](faq.md)。
